    Что сделать вам (по шагам)

    1. Оставьте этот сервис включённым — окно с Docker не закрывайте, пока пользуетесь «живой» Аминой в Telegram.
    2. Интернет в телефон — запустите на ПК программу туннеля (cloudflared) или скрипт start-windows.ps1 -Gpu -Tunnel. Появится адрес вида https://…trycloudflare.com.
    3. Телеграм — откройте мини-приложение Амины → раздел «Локальный PC» → вставьте этот https-адрес и тот же секрет, что в файле .env (параметр AMINA_AVATAR_SECRET).
    4. Лицо как на Civitai — это не сайт, а картинка: положите свой портрет в папку amina-avatar-local/assets/face.png и перезапустите Docker.

    Открыть мини-приложение в браузере

    Страница не открывается?

    Сервис на этом адресе появляется только когда он запущен на ПК. В PowerShell из папки проекта: .\scripts\diagnose-panel.ps1 Затем либо Docker: docker compose up -d --build в amina-avatar-local (Docker Desktop должен быть включён), либо без Docker (только панель и простой режим без Wav2Lip-GPU): .\scripts\start-panel-local.ps1 Открывайте http://127.0.0.1:8765/ — не https. Если меняли порт в .env, подставьте свой.

    Подсказка

    Если что-то «не живое» — чаще всего не запущен туннель или в Telegram указан другой секрет. Эта панель работает только на вашем ПК ().
