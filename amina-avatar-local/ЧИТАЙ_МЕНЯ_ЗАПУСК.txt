Сначала (один раз), если ПК "чистый":

  INSTALL_RUNTIME.bat

Потом всегда:

  START_AMINA.bat

Если PowerShell ругается на "придумайте" или "Missing )":
  откройте start-everything.ps1 в Блокноте - в самом верху должна быть строка
  SCRIPT_VERSION 2025-03-21-ascii
  Если её нет - файл старый (OneDrive не подтянул). Скопируйте проект заново или возьмите файл из Git.

Что произойдёт:
1. Сам настроит .env и создаст SECRET_FOR_TELEGRAM.txt (секрет для Telegram).
2. Попробует запустить Docker (сначала с видеокартой, если не выйдет — без).
3. Откроет браузер с панелью http://127.0.0.1:8765/
4. Откроет блокнот с секретом — вставьте его в мини-приложение Амины → «Локальный PC».

Если Docker не установлен — поставьте Docker Desktop (docker.com) и запустите снова.
Или установите Python 3 с python.org (галочка Add to PATH) — тогда скрипт сам поднимет простой сервер.

Родительская папка проекта: можно также запустить START_AMINA.bat в корне репозитория.
