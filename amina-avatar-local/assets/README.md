# Референс лица

Положите сюда файл **`face.png`**: **фото анфас, одно лицо**, хороший свет, **не меньше 1024×1024** (лучше 1536+). Видео собирается в вертикали **720×1280** (или ваши `AVATAR_VIDEO_*` в `.env`): кадр **cover** — лицо крупно по центру, как в сторис.

Заглушка из `create-minimal-face-placeholder.ps1` годится только для проверки пайпа; для нормального вида замените на **портрет** (в т.ч. референс после генерации в Civitai и т.п.). В репозиторий персональное фото не коммитьте.

Для **Wav2Lip** без `face.png` сервис вернёт ошибку. Без файла в режиме **ffmpeg** будет только тёмный фон и звук.
