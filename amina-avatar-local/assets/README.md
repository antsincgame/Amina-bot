# Референс лица

Положите сюда файл **`face.png`** (квадратное фото, одно лицо крупно, желательно ~512×512).

Источник «стиля» (в т.ч. после генерации в духе Civitai) — ваш выбор; в репозиторий реальное лицо не коммитьте, если это персональные данные.

Для **Wav2Lip** без `face.png` сервис вернёт ошибку. Для CPU-only `ffmpeg` допустима заглушка (тёмный кадр), но видео будет без лица.
